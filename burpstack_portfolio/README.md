# Aprajita's Personal Portfolio

## Project description
A beginner-friendly, multi-page personal portfolio created with HTML only for BURPSTACK Task 01. It introduces the developer, shares learning interests and projects, and provides a sample contact form.

## Pages included
- `index.html` — Home and introduction
- `about.html` — About, education, skills and interests
- `projects.html` — Project descriptions
- `contact.html` — Accessible contact form structure

## Technologies used
- HTML5
- Git and GitHub for version control and hosting workflow

## Run locally
Download or clone this repository, then open `index.html` in a browser. Use the navigation links to visit the other pages.

## Before publishing
- Replace the profile image placeholder with your own image, or another image you have permission to use.
- Replace generic social profile links with your actual profiles.
- Add real project repository/live links when available.
- The contact form is a front-end demonstration only. It does not send messages until a backend or form service is configured.

## Learning note
This project uses semantic HTML, headings, navigation, links, lists, labels, form controls, descriptive metadata, and accessible image text. Review each page and make sure you can explain what the tags do before submitting.
